# Hoobs Companion Web App

The **Hoobs Companion App** is a Progressive Web Application (PWA) that connects stream viewers directly to the live server, their viewer profile, and real-time interactive stream perks.

🌐 **Launch App**: [https://app.hoobs.live](https://app.hoobs.live)

---

## 📱 Features & Capabilities

- **Real-Time Active Perks**:
  - Live countdown timers for active **2X Loot Multipliers**.
  - Remaining charge counters for **50% OFF Shop Coupons**.
  - Real-time WebSocket synchronization (EVENT_PERKS) when buffs are won from the Code Wheel or gifted via !give.
- **Profile & Statistics**:
  - Live Hoob Loot balance, total watch hours, and leaderboard rankings.
  - Linked in-game Minecraft player stats, skin preview, and clan membership.
- **Interactive Stream Events**:
  - Real-time event notifications for Boss Battles, Giveaways, Raffles, and Stream Polls.
- **Ms Bacon's Secret Codes**:
  - Dedicated secret code drop interface for eligible viewers.

---

## 🔗 How to Link Your Account

1. Open the companion app at [https://app.hoobs.live](https://app.hoobs.live).
2. Type in YouTube stream chat or in-game:
   `
   !app
   `
3. Follow the one-time authentication link to link your YouTube viewer identity securely to your companion app instance.
