# Hoobs Live Handbook

Join our 24/7 vanilla survival public server for non-stop fun — no Minecraft needed! Watch as the camera auto-spectates players, or take control with interactive chat !commands to explore live. Don't just watch, jump in and be part of the action!

## 🎥 Camera & Stream Controls
- !random / !next — Spectate a random player or location (10s cooldown)
- !spectate / !s — List all spectating options
- !spectate [player] / !s [player] — Watch a specific player
- !spectate [+location] / !s [+location] — Watch a specific build/location
- !players / !miners — List all players currently online in the server
- !places / !places [player] — List all available community locations to spectate
- !more — Continue watching current location/player
- !back — Return to the previous location/player
- !say [message] — Send Text-to-Speech message to stream

## ⚔️ NPC & PvP Commands
- !npc — Summon and preview your personal interactive NPC
- !npc stats — View wins, losses, kills, and weekly PvP challenge progress
- !npc armor — View unlocked armor sets based on hours and loot rank
- !npc color [color] — Set custom glowing aura color
- !npc effects [particle] — Set custom particle effects
- !npc weapon [weapon] — Set custom weapon loadout
- !npc type [entity] — Set custom entity disguise
- !battle — Start or join a battle royale event for everyone in chat
- !pvp [player] — Challenge another viewer's NPC to an arena battle on stream

## 🪙 Hoob Loot & Economy
- !loot / !bal / !balance / !money — Check your (or another viewer's) Hoob Loot balance, hours, and active perks
- !free — Claim free periodic loot (1 min cooldown)
- !daily — Claim daily loot bonus (1 to 1,000,000 Loot, 24h cooldown)
- !weekly — Claim weekly loot bonus (1 to 5,000,000 Loot, 7 day cooldown)
- !monthly — Claim monthly loot bonus (1 to 10,000,000 Loot, 30 day cooldown)
- !bacon — Grab the crispy bacon for up to 110,000 free loot during the 30-second burn window!
- !give [viewer] [amount|2x|coupon|buffs] — Gift loot or active perks (2X Multipliers, 50% OFF Coupons, Buff Bundle) to another viewer
- !coupons / !buffs / !perks / !discount — Check your active perks (remaining 2X Multiplier time and unused 50% OFF shop coupons)
- !code [code] / !c [code] — Redeem secret codes from YouTube Shorts or live 2FA codes for Ms Bacon's Code Wheel
- !rob [viewer] / !r [viewer] — Attempt to rob another viewer (30% success rate). Also !rob #[rank] to rob by leaderboard rank
- !police — Hire police protection against robberies for 12 hours (costs 1,000,000 Loot)
- !bounty [player] [amount] — Place a bounty on an in-game Minecraft player
- !wanted — View all active open player bounties
- !raffle [number] — Guess the lucky number to win loot when a raffle is active

## 🛒 Interactive Shop & Items
- !shop — View currently available shop items and prices (rotates every 10 minutes)
- !refresh — Manually refresh the shop rotation (costs 100,000 Loot, every 10th purchase of the same item is free!)
- !diamond [player] — Send a real diamond to an in-game player (5 min cooldown)
- !sheep [player] — Drop a sheep on a player (Members can choose color: !sheep [player] [color])
- !shovel — Receive a golden land claim shovel and inspection stick (5 min cooldown)
- !letter [player] [message] — Send an in-game written book directly to a player's inventory
- !surprise — Send a random surprise item to a random online player
- !xp [player] — Send XP orbs to a player (level scales with weekly usage)
- !melt [player] — Melt all snow within 10 blocks of a player (costs 1M Loot)
