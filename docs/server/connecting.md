# How to Connect to Hoobs Live

Hoobs Live is a public 24/7 cross-play Minecraft server powered by Paper 26.2 (1.21.2+). Players on **Java Edition**, **Bedrock Edition**, **iOS**, **Android**, **Xbox**, **PlayStation**, and **Nintendo Switch** can all explore and build together in the same world!

---

## ☕ Java Edition (PC / Mac / Linux)

1. Launch **Minecraft Java Edition** (Target version: **1.21.2+** / **26.2**).
2. Click **Multiplayer** → **Add Server**.
3. Set **Server Name**: `Hoobs Live`
4. Set **Server Address**: `hoobs.live` (Port `25565` is default).
5. Click **Done** and double-click to connect!

---

## 📱 Bedrock Edition (Windows 10/11, iOS, Android, Fire OS)

1. Launch **Minecraft Bedrock Edition**.
2. Click **Play** → Navigate to the **Servers** tab.
3. Scroll down and click **Add Server**.
4. Set **Server Name**: `Hoobs Live`
5. Set **Server Address**: `br.hoobs.live` (or `bedrock.hoobs.live`)
6. Set **Port**: `19132`
7. Click **Save** and select the server to join!

---

## 🎮 Console Players (Xbox, PlayStation, Nintendo Switch)

Console editions of Minecraft cannot add custom servers by default, but you can easily join using the **BedrockConnect DNS trick**:

1. Go to your console's **Network Settings** → **Advanced Settings** → **DNS Settings**.
2. Change DNS configuration to **Manual**.
3. Set **Primary DNS**: `104.238.130.180` (or `132.145.68.215`).
4. Set **Secondary DNS**: `1.1.1.1` (or `8.8.8.8`).
5. Save your network settings and restart Minecraft.
6. Under the **Servers** tab, click on any of the featured partnered servers (e.g. The Hive or Mineplex).
7. Instead of loading that server, a custom BedrockConnect server list will appear.
8. Click **Direct Connect** (or **Manage Server List**), enter `br.hoobs.live` with port `19132`, and join!

## 🛡️ Allowed & Recommended Client Mods

To preserve the authentic vanilla survival experience while giving you the best performance, the following client mods are fully allowed:

- **Performance & Graphics**: Sodium, Lithium, Iris Shaders, OptiFine, FerriteCore, Continuity.
- **Recording & Visuals**: Replay Mod, Camera tools (for non-competitive recording).
- **HUD & Info**: Mini-HUD, AppleSkin, Simple Coordinates, Vanilla-accurate minimaps (exploring only).

> **Prohibited Mods**: X-ray texture packs/mods, Fly hacks, Auto-clickers/macros, Auto-fishing bots, and Hacked/cheat clients are strictly detected and result in automatic bans.
